A face tile behaves like a digit

Every state, every motion and every rule is the digit tile's. The inlay is the only difference, so this sheet is mostly a check that nothing else had to change — and the two places where something did.

03 · Rack order

Digits sort first, ascending, as today. Faces follow in a fixed order — ✳, O, E, then ranges by lowest digit — so a player's eye finds the specials at the same end every round. The rack still re-sorts only at the resolve.
