# 2026-11-09 — Puzzle leaves ozterisk

## Decisions

All of these are Ori's, made in session.

- **Puzzle becomes its own game.** Puzzle's pitch is strong, but M8's face-up
  build doesn't fit ozterisk.
  - ozterisk's thesis (`product.md` §1.1) is an inventory loop under random
    draws. Puzzle is a planning puzzle with nothing random after the deal.
  - So Puzzle leaves ozterisk as a separate game, with its own name and
    identity.
- **M10 is mothballed.** First the window was to be tried in ozterisk, and its
  build would no longer wait for M8's baseline result. Later in the same
  session Ori mothballed the concept: "we might need to think this over". Its
  design and sims stay on `feat/M10-puzzle-window`.
- **Order.** The separate game comes first. Then ozterisk tries another
  experimental mode.

## The separate game

- **Its design** is `docs/superpowers/specs/2026-11-09-puzzle-spin-off-design.md`.
  It is recorded here until the new repo exists, and then moves there.
  - Two modes. **Daily** is one table a day, the same for everyone; the solver
    chooses each one ahead of time so that it needs a sacrifice. **Practice**
    deals a fresh random table each time.
  - A reload resumes the daily where the player left off, as Wordle does.
- **What ozterisk avoids, the new game may use.** Ori reads ozterisk's lines
  against seeds, replayable runs and result URLs as "avoid", not "ban".
  ozterisk's `AGENTS.md` words them as "do not", and agents follow that
  wording, so the new repo rewrites them rather than reinterpreting them.
  ozterisk's own text is unchanged.
- **Its repo is seeded from `feat/M8-puzzle-prototype` at `3ccd37b`.** That
  branch must stay on GitHub after #205 is closed.
- **Its identity** is being designed on a Claude design canvas, private to Ori.

## M8's end rule, stated exactly

A run ends early when the hand holds **fewer tiles** than the next answer
needs. A hand with enough tiles but the wrong digits can still answer wrong and
play on. The solver and every par assume this rule. Claude first wrote "can't
spell the next answer" in the new game's design and on its canvas, and the
design's builder check caught it before Ori read either.
